  - 이미지 처리 //ex. 섬네일 등
- reply
  - 삭제, 수정 기능
- test code
  - 작성안된 것 마무리하고 다음 작업으로 넘어가기
- app-runner
  - 필요한 데이터에 맞게 정리하기
